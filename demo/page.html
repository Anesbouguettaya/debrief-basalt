Prototype · candidature stage / alternance IA Engineer · Basalt

Le conseiller raccroche. Le CRM est déjà à jour.

Débrief transforme un appel en compte rendu, fiche HubSpot, contrôle du devoir de conseil et de la LCB-FT, puis e-mail de relance. Chaque information est sourcée dans l'appel, chaque règle de conformité est du code testé, et rien n'est écrit sans la validation du conseiller.

Conçu et codé par Anes Bouguettaya, octobre 2026. Appels, clients et conseillers fictifs.

    Sous le capot
    Le modèle comprend, le code décide
    
      
    Dans une fintech régulée, un agent utile est un agent auditable. Quatre partis pris structurent le code, que vous pouvez lire ci-dessous sans quitter la page.
    
    
    
    
    
      
    Le code décide
    Claude extrait des faits dans un schéma imposé. Seuils, plafonds et escalades sont des règles Python versionnées et testées, jamais des consignes de prompt.
    
      
    Aucun champ sans source
    Chaque valeur arrive avec une citation de l'appel. Le code la cherche dans la transcription ; si elle n'y est pas, la valeur n'atteint pas le CRM.
    
      
    Le conseiller valide
    Débrief prépare le diff et les requêtes HubSpot, rien n'est écrit sans validation. En escalade LCB-FT, aucune relance ne part et les données sensibles restent hors du CRM.
    
      
    Mesuré dès le jour 1
    Coût et tokens par appel, taux de citations retrouvées, jeu d'évaluation où les erreurs critiques sont comptées à part : de quoi comparer modèles et prompts sur des faits.
    
    
    
    
    
      
    
      
    
        
    
        
    
      
    
    
    
    
    
      
    
        
    Pourquoi Python ici, et pas n8n ?
    
        
    n8n ou Make sont parfaits pour la plomberie : le webhook de fin d'appel de l'outil de téléphonie, la transcription, la notification Slack. La logique de conformité, elle, doit être testée unitairement, versionnée et auditable : elle vit en Python.
    
        
    En production, n8n déclenche et Python décide : un nœud HTTP appelle Débrief, le conseiller valide dans HubSpot.
    
      
    
      
    
        
    La pile
    
        
    Sorties structurées de l'API Claude (schéma Pydantic imposé), cache du prompt système, modèle rapide pour la relance. API HubSpot CRM v3 sans dépendance. Le même agent est exposé comme serveur MCP, utilisable depuis Claude.
